🚀 Cómo subir a GitHub y tener tu enlace público

Todo el código está empaquetado como una aplicación web estática (HTML, CSS y JavaScript moderno). Para tener tu link gratuito listo para abrir y compartir con quien quieras:

Paso 1: Crear un nuevo repositorio en GitHub

  1. Ingresa a tu cuenta de GitHub.com/new.
  2. Ponle nombre a tu repositorio (por ejemplo: sala-entretenimiento o peru-lounge).
  3. Déjalo en modo Public (Público).
  4. Haz clic en Create repository.

Paso 2: Subir el proyecto

Abre la terminal en la carpeta de este proyecto y ejecuta:

git remote add origin https://github.com/TU_USUARIO/TU_REPOSITORIO.git
git branch -M main
git push -u origin main

Paso 3: Activar GitHub Pages (Tu link directo)

  1. En tu repositorio de GitHub, entra a Settings (Configuración) > pestaña Pages (a la izquierda).
  2. En Branch, selecciona main y carpeta / (root), luego presiona Save.
  3. ¡Listo! En 1 minuto tendrás tu enlace activo:
    https://TU_USUARIO.github.io/TU_REPOSITORIO/

Cualquiera que haga clic en ese enlace entrará directamente a escuchar radios peruanas y jugar sin instalar absolutamente nada.
